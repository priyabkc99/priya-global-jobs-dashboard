Introduction

We are seeking an experienced DevOps Engineer to join a high-performing technology team delivering secure, scalable, and resilient cloud-based platforms within a regulated environment.

This role is ideal for a hands-on engineer passionate about automation, infrastructure-as-code, CI/CD optimisation, cloud operations, and operational reliability. You will play a key role in improving software delivery efficiency, platform stability, observability, and cloud governance across mission-critical systems.

Duties & Responsibilities

Essential Experience & Skills:

 

7+ years of hands-on experience in DevOps and/or Site Reliability Engineering (SRE) roles.
Strong focus on:
DevOps engineering
CI/CD automation
Infrastructure automation
Cloud operations
AWS Certified SysOps Administrator – Associate
AWS Certified Solutions Architect – Associate
Strong AWS experience within enterprise-scale environments.
Experience working with PCI-DSS compliant systems or highly regulated industries.
Proven experience implementing CI/CD pipelines across large delivery organisations.
Strong Infrastructure-as-Code and workload automation capability.
Experience implementing observability and monitoring solutions for hybrid and cloud environments.
Strong networking knowledge including TCP/IP, DNS, routing, firewalls, and load balancing.
Understanding of the AWS Well-Architected Framework and cloud best practices.
Strong Linux administration and scripting capability.

 

Preferred Technologies:

Experience with some or all of the following:

AWS
Terraform / CloudFormation
Kubernetes / Docker
Jenkins / GitLab CI / GitHub Actions
Python / Bash scripting
Prometheus / Grafana
ELK / OpenSearch
Ansible
GitOps tooling

 

Key Responsibilities:

 

Design, build, and maintain scalable CI/CD pipelines across multiple delivery teams.
Automate infrastructure provisioning and configuration management within AWS environments
Improve deployment reliability, release automation, and operational efficiency
Implement observability, monitoring, alerting, and logging solutions across hybrid and cloud-native platforms
Collaborate with development, infrastructure, security, and architecture teams to support reliable software delivery
