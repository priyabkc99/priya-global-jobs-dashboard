At CMSN Group Pty Ltd, we build innovative software products and digital platforms across AI, enterprise software, cloud infrastructure, robotics, e-commerce, managed IT services, renewable energy, and digital transformation. Since 2013, we've been helping businesses modernize their technology through scalable software and cloud solutions.

We're looking for a skilled DevOps Engineer to help design, automate, and manage the cloud infrastructure that powers our growing portfolio of products, including AI platforms, ERP systems, eCommerce solutions, robotics applications, and SaaS products.

About The Role

As a DevOps Engineer, you will bridge development and operations by building secure, scalable, and highly available cloud infrastructure. You'll automate deployments, improve system reliability, implement Infrastructure as Code (IaC), and enhance our CI/CD pipelines to enable rapid software delivery.

Key Responsibilities


Design, build, and maintain cloud infrastructure on AWS, Azure, or Google Cloud.
Develop and manage CI/CD pipelines using GitHub Actions, GitLab CI, Azure DevOps, or Jenkins.
Implement Infrastructure as Code using Terraform, CloudFormation, or Ansible.
Deploy and manage containerized applications using Docker and Kubernetes.
Monitor application performance, availability, and security.
Configure automated backups, disaster recovery, and high-availability solutions.
Implement DevSecOps best practices and security automation.
Manage Linux servers, networking, DNS, SSL certificates, and load balancers.
Support development teams by improving deployment automation and operational efficiency.
Troubleshoot infrastructure, networking, and deployment issues.
Maintain documentation and operational procedures.
Continuously improve cloud performance, scalability, and cost optimization.


Required Skills


Bachelor's degree in Computer Science, Information Technology, Software Engineering, or a related field.
3+ years of experience in DevOps, Cloud Engineering, or Site Reliability Engineering.
Strong experience with Linux system administration.
Experience with one or more cloud platforms:
Amazon Web Services (AWS)
Microsoft Azure
Google Cloud Platform (GCP)
Strong knowledge of:

Experience with scripting using:

Experience with monitoring tools such as Prometheus, Grafana, ELK Stack, or Datadog.

Nice to Have


AWS, Azure, or Google Cloud certifications.
Experience with GitHub Actions, Jenkins, or Azure DevOps.
Knowledge of Helm and Kubernetes Operators.
Experience managing PostgreSQL, MySQL, Redis, or MongoDB.
Familiarity with Kafka, RabbitMQ, or MQTT.
Experience supporting AI/ML infrastructure and GPU workloads.
Knowledge of security compliance, vulnerability management, and DevSecOps.
Experience with microservices architecture and API gateways.
