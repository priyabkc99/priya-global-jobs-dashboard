About Us

Straive Private Limited (Erstwhile LearningMate Solutions Pvt. Ltd) is is a global leader in data analytics and AI operationalization, helping enterprises embed advanced AI and data capabilities into core business workflows to deliver measurable business outcomes and ROI. With a workforce of ~20,000 professionals serving 350+clients across 30+ markets, Straive combines technical scale with deep domain expertise. About the Role

We are seeking a highly motivated and experienced DevOps Engineer to join our growing engineering team. The ideal candidate will have 5–8 years of professional experience, a strong background in cloud infrastructure, CI/CD pipelines, and configuration management, and a passion for automating processes and improving system reliability. This role is pivotal in ensuring the stability, scalability, and performance of our core products.(Night Shift : 9 PM to 6 AM)




Key Responsibilities

CI/CD Pipeline Management: Design, implement, and maintain robust, automated continuous integration and continuous deployment (CI/CD) pipelines using tools like Team Foundation Server, Jenkins, GitLab CI, or GitHub Actions.
Infrastructure Management (IaC): Manage and provision cloud infrastructure (AWS (must have) /Azure/GCP (optional)) using Infrastructure as Code (IaC) tools, primarily Terraform or CloudFormation/ARM Templates.
Webservers: IIS, App pools, Apache, Nginx
Experience of the build and deployment process of Microsoft .Net based web applications using MSBuild along with deployment scripts creation using Powershell on AWS servers and services.
Experience of the build and deployment process of Angular + Node and .Net core based web applications and containers using docker along with deployment scripts creation using shell + powershell scripting
Containerization & Orchestration: Deploy, scale, and manage containerized applications using Beanstalk, ECS, Docker and Kubernetes.
Monitoring and Alerting: Implement and manage comprehensive monitoring, logging, and alerting systems (Prometheus, Grafana, Datadog/NewRelic, ELK stack) to ensure high availability and proactive issue detection.
Automation & Scripting: Write and maintain scripts (e.g., Powershell, Python, Bash, or Groovy) to automate repetitive tasks, system maintenance, and deployment processes.
Security & Compliance: Implement security best practices within the infrastructure and pipelines (e.g., vulnerability scanning, secret management).
Collaboration: Work closely with software development and QA teams to troubleshoot environment issues, define release strategies, and implement necessary infrastructure changes.
System Reliability: Participate in on-call rotations and incident response, perform root cause analysis, and continuously drive improvements for system reliability and performance.
Collaboration: Work closely with software development and QA teams, and interact directly with international stakeholders and customers to troubleshoot environment issues, define release strategies, and implement necessary infrastructure changes.
Hands-on experience using Jira and Confluence within agile environments, collaborating closely with cross-functional teams through daily standups, sprint ceremonies, and regular team syncs to ensure transparent communication and efficient delivery.
Hands-on experience integrating automated test suites into CI/CD pipelines, enabling continuous validation of application quality. Skilled in orchestrating unit, integration, and end-to-end tests within build workflows to ensure reliable deployments, faster feedback loops, and consistent delivery across environment




Required Qualifications & Skills (5–8 Years Experience)

Proven experience (5-8 years) as a Sr. DevOps Engineer, Site Reliability Engineer (SRE), or similar role.
Cloud Expertise: Expert-level proficiency with at least one major public cloud provider (AWS,).
Containerization: Deep working knowledge of Docker and experience with an orchestration platform like Kubernetes (K8s) & Amazon ECS.
IaC: Strong experience with Infrastructure as Code tools such as Terraform, Cloudformation.
CI/CD Tools: Extensive experience configuring and managing CI/CD tools (e.g., Jenkins, GitLab CI, GitHub Actions).
Operating Systems: Solid understanding of Linux/Unix administration and networking concepts.
