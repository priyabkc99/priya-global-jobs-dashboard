Role : Senior DevOps Engineer

Experience : 10+ Years

Location : Sydney

Job Type : Full Time (Permanent)




Desirable :




Strong experience in infrastructure operations, application builds, and deployments across environments.
Expertise in DevOps automation and CI/CD implementation.
Deep understanding of CI/CD tools and practices.
Hands-on experience with:
Git, Jenkins, Bamboo, Ansible
Linux/Unix administration
Tomcat, Spring Boot, Apache, IBM HTTP Server, WebSphere
Experience with cloud platforms such as AWS and Azure.
Knowledge of container technologies including Kubernetes and OpenShift.
Proficiency with monitoring and observability tools such as Dynatrace and Splunk.
Familiarity with DB2, PostgreSQL, and MySQL databases.
Experience working in Agile/Scrum environments.
Strong planning, prioritization, and stakeholder communication skills.




Essential Skills

AWS / Azure Cloud
Jenkins
Ansible
Git / GitHub
Linux Administration
CI/CD Pipeline Implementation
Infrastructure as Code (IaC)
Kubernetes / OpenShift
Java Platform Support
Dynatrace / Splunk Monitoring
Production Support & Troubleshooting




Key Responsibilities :




Design, develop, and manage CI/CD pipelines using Jenkins, Ansible, GitHub, and related tools.
Develop automation scripts for application deployment, configuration, and operational management.
Manage Linux and Windows environments through Infrastructure as Code and automation.
Implement and support DevOps toolchains including AWS DevOps, Git, Jenkins, SVN, and Ansible.
Maintain and administer Java/J2EE application platforms and middleware.
Support production and non-production environments, including troubleshooting and release support.
Contribute to DevOps strategy, tooling standards, and automation frameworks.
Document processes and provide knowledge transfer to development and operations teams.
Participate in production release activities and operational support.
