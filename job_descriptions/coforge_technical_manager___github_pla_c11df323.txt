Role: Technical Manager - GitHub Platform Uplift

Skills: Github, DevSecOps, Delivery & Stakeholder Management

Location: Sydney

Duration: Permanent




Role Overview




We are seeking an experienced Technical Manager to lead the uplift and modernization of GitHub and DevSecOps platforms within a large enterprise environment. This role combines technical leadership and hands-on engineering, driving platform transformation, secure software delivery, automation, and engineering enablement initiatives.




Key Responsibilities




Delivery & Stakeholder Management

Lead platform uplift initiatives from planning through delivery.
Manage project scope, risks, dependencies, and stakeholder communications.
Coordinate engineering, cloud, security, and infrastructure teams to achieve delivery outcomes.
Provide governance, reporting, and implementation oversight.

GitHub Platform Management

Administer GitHub Enterprise environments, including repository governance, access controls, and security settings.
Lead GitHub migration and onboarding activities.
Establish standards and best practices for GitHub usage and governance.

DevSecOps & CI/CD Engineering

Design and improve secure CI/CD pipelines and platform capabilities.
Implement DevSecOps controls across source code, dependencies, secrets, and container platforms.
Drive automation, standardization, and operational excellence within software delivery processes.

Automation & Operational Readiness

Develop automation solutions using scripting and Infrastructure-as-Code.
Implement monitoring, dashboards, and platform observability.
Produce technical documentation, runbooks, and support procedures.
Conduct knowledge transfer and enablement sessions for engineering teams.




Required Experience

Essential

8+ years' experience in Platform Engineering, DevOps, DevSecOps, or Cloud Engineering.
Strong experience with GitHub Enterprise administration and migration programs.
Expertise in CI/CD platforms, GitHub Actions, and pipeline automation.
Practical experience implementing DevSecOps and secure software delivery practices.
Kubernetes and container platform experience.
Strong automation and scripting skills.
Proven ability to lead complex technical initiatives and manage stakeholders.




Desirable

Experience with SAML SSO, SCIM, identity integration, GitOps, and self-hosted runners.
Exposure to regulated or highly governed environments.
Understanding of security and compliance frameworks.




Technical Skills

GitHub Enterprise Administration
GitHub Actions & CI/CD Pipelines
DevSecOps & Secure SDLC
Kubernetes & Container Platforms
Infrastructure as Code
Python, Bash, PowerShell
Grafana, Open Telemetry, Monitoring & Alerting
Developer Portals and Internal Developer Platforms (IDP)
Bachelor's degree in computer science, Information Technology, Engineering, or related field.
GitHub Certifications desirable.
AWS and/or Kubernetes certifications preferred.
