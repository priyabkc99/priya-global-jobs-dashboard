Job Description

As a DevOps Engineer, you will play a critical role in designing, implementing, and supporting cloud-native infrastructure and DevOps practices across enterprise applications. You will partner closely with software engineering, platform, and operations teams to deliver reliable, secure, and scalable solutions leveraging Azure, GitHub, Kubernetes, and modern CI/CD pipelines.

You will report to the Manager, Software Engineering and work in a hybrid environment based in Pune, India.

Your Responsibilities


Build and maintain CI/CD pipelines using Azure DevOps and GitHub Actions.
Manage cloud infrastructure and services on Microsoft Azure.
Deploy and support containerized applications using Docker and Kubernetes.
Automate infrastructure provisioning and operational processes using Terraform and scripting.
Monitor, troubleshoot, and optimize application performance and platform availability.
Implement DevOps best practices, security controls, and release automation.


The Essentials - You Will Have


Bachelor’s degree in Computer Science, Engineering, or related field, or equivalent experience.
5+ years of experience in DevOps, Cloud Engineering, or Infrastructure Automation.
Strong experience with Azure, Azure DevOps, GitHub Enterprise, and GitHub Actions.
Hands-on experience with Docker, Kubernetes, and CI/CD pipeline implementation.
Proficiency in PowerShell, Bash, or Python scripting.
Experience with Infrastructure as Code tools such as Terraform or ARM/Bicep.
Knowledge of Linux and Windows environments.


The Preferred - You Might Also Have


Experience with GitOps tools (FluxCD/ArgoCD).
Knowledge of Azure Key Vault, Vault, or certificate management solutions.
Experience with Artifactory/Nexus and cloud monitoring tools.
Azure certifications (AZ-104, AZ-400) preferred.
