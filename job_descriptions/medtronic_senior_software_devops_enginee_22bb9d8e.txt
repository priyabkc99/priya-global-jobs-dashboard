A Day in the Life

As a Senior Software DevOps Engineer, you will design, automate, and maintain CI/CD pipelines and cloud infrastructure supporting web, desktop, and mobile applications. You will partner with development teams to improve build and deployment processes, strengthen system reliability and security, and troubleshoot issues across Windows and Linux environments.

Primary Responsibilities


Design, build, and maintain CI/CD pipelines for web, desktop, and mobile applications.
Automate application build, signing, packaging, release, and deployment processes using Azure DevOps and related tools.
Automate Amazon Web Services (AWS) infrastructure provisioning and configuration using Infrastructure as Code (IaC).
Partner with development teams to optimize application build and deployment processes.
Monitor and improve system reliability, availability, and performance.
Manage Git repositories, version control practices, and branching strategies.
Troubleshoot and resolve build, infrastructure, system, and deployment issues.
Implement security best practices across development, infrastructure, and deployment processes.



Required Qualifications


Bachelor's degree in Computer Engineering or Computer Science with 8+ years of engineering experience.
Experience with AWS services, including Amazon Elastic Compute Cloud (EC2), Amazon Simple Storage Service (S3), AWS Lambda, and Amazon Relational Database Service (RDS).
Experience with CI/CD platforms and tools such as Azure DevOps, Jenkins, or GitLab CI, and version control using Git.
Experience with Infrastructure as Code using Terraform or AWS CloudFormation and scripting using Python, Bash, or PowerShell.
Experience supporting application builds and deployments across Windows and Linux environments.



Preferred Qualifications


Experience with Docker and Kubernetes.
Experience with monitoring and observability tools such as Prometheus, Grafana, or Amazon CloudWatch.
Experience with iOS or Android application build and deployment processes.
Experience in the medical device industry or another regulated industry.
Experience with security and risk analysis.
