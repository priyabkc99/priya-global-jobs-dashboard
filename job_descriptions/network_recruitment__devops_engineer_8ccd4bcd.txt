Calling all DevOps Engineers! A leading fintech is looking for a cloud and automation specialist to help scale and optimise mission critical platforms in a high growth environment. If you have deep AWS experience, thrive in complex cloud environments, and enjoy driving DevOps best practices, security, and automation, this is an opportunity to work with cutting edge technologies while making a real impact on platform reliability and performance.
Duties & Responsibilities
Qualifications:

Relevant IT Degree or Diploma advantageous
Cloud and DevOps certifications highly advantageous
 
Requirements:

7+ years’ experience in DevOps, Cloud Infrastructure, or Systems Engineering
Strong AWS experience
Linux administration experience
Terraform Infrastructure as Code experience
Docker, Kubernetes, and Argo CD experience
CI/CD experience with GitLab, GitHub Actions, or Jenkins
Strong scripting skills in Python, Bash, or Ruby
Experience with Prometheus, Grafana, ELK, or Loki
 
KPAs:

Build and maintain cloud infrastructure and deployment pipelines
Implement Infrastructure as Code and automation solutions
Drive cloud security, monitoring, and observability initiatives
Support disaster recovery, redundancy, and platform resilience
Collaborate with Engineering, Security, and Architecture teams
Improve reliability, scalability, and developer experience across platforms
