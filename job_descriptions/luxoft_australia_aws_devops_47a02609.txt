Project details

An opportunity is available to join the OTC Clearing team, which is responsible for the delivery, support, and modernization of the Calypso platform for our client, a leading Australian financial market infrastructure provider.




As part of the technology transformation agenda, you will participate in strategic initiatives such as Calypso cloud migration, Aurora PostgreSQL adoption, DevOps automation enhancement, GitLab SaaS migration, observability improvements, and overall platform modernization. The team operates within a cross-functional Agile framework, encompassing Engineering, Quality Engineering, DevOps, Product, Business Analysis, and Application Support roles.




Responsibilities

- Build, maintain, and support AWS cloud infrastructure hosting the core platform and related services.

- Develop and manage CI/CD pipelines using GitLab SaaS to enable automated, repeatable deployments across environments.

- Support migration of workloads from on-premise infrastructure to AWS cloud platforms.

- Implement and maintain Infrastructure as Code (IaC) using Terraform and Ansible.

- Automate application deployments, database refreshes, environment provisioning, and operational support processes.

- Collaborate with Engineering, QA, Application Support, Infrastructure, and Architecture teams to enhance delivery efficiency and platform resilience.

- Support migration activities including deployment automation, configuration management, and environment support for Aurora PostgreSQL.

- Drive observability improvements through logging, monitoring, alerting, OpenTelemetry, CloudWatch, and associated tools.

- Manage secrets, certificates, credentials, and access controls following enterprise security patterns and tools.

- Support release governance, production readiness assessments, change management, and incident response activities.

- Troubleshoot application, infrastructure, networking, and deployment issues across multiple environments.

- Contribute to DevOps standards, reusable pipeline patterns, and cloud deployment frameworks within the technology domain.




Requirements

9+ years of experience in DevOps, Platform, Cloud Engineering, and Site Reliability Engineering to support and optimize cloud-based infrastructure. They possess advanced hands-on skills with AWS services including compute, container orchestration, storage, identity and access management, networking, monitoring, secrets management, and databases.




Hard skills include:

- Experienced in implementing DevOps pipeline for leading capital markets trading applications like Calypso, Murex, FIS..etc

- Designing and managing CI/CD pipelines using GitLab SaaS for automated deployments and release orchestration

- Implementing Infrastructure as Code with Terraform alongside configuration management via Ansible

- Administering Linux systems and developing automation scripts in Bash and Python

- Supporting mission-critical production environments within regulated industries

- Applying deployment strategies, change and environment management, and release governance best practices

- Establishing monitoring, logging, observability, and incident response frameworks

- Executing comprehensive troubleshooting across applications, databases, infrastructure, and networks

- Managing secrets securely using tools like HashiCorp Vault




Soft skills emphasize effective communication and collaboration:

- Engaging with diverse teams including Engineering, QA, Operations, Security, and Architecture

- Facilitating stakeholder alignment to ensure successful project delivery and operational stability
