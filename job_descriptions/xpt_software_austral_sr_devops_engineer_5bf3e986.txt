As a Sr DevOps Engineer you will be reporting directly to the DevOps Lead. Along with other members of the DevOps team, you will work closely with our development team and operations teams to support the deployment, automation and monitoring of our applications and infrastructure. You will be involved in building tools and processes that will enhance the development cycle and improve reliability of our systems.

Key Responsibilities –


Assist in the deployment and configuration of applications and services (Kubernetes, Lambda, ECS, S3)
Maintain and manage cloud infrastructure (AWS - EC2, Cloudformation, S3, ALB, ELB, Lambda, ECS, ECR, Elasticache, API Gateway)
Liaise with other technology teams in AMP
Implement new CI/CD pipelines and automation scripts and troubleshoot any issues arising with existing pipelines and scripts (Jenkins, Github
Actions)
Monitor system performance and troubleshoot problems (Kibana, Cloudwatch, DataDog)
Maintain and Enhance the Digital environment (MongoDB / AWS / Kubernetes / Lambda / ECS based platform)
Use CI/CD methodologies to improve efficiency
Support and assist in projects. Nonproduction and production developments
Identifying and implementing platform improvements
Stay updated on the latest DevOps tools, technologies and practices


Mandatory skills –


Linux System Administration (Redhat)
Experience managing Kubernetes clusters and its administration
AWS proficiency (EC2, Cloudformation, S3, ALB, ELB, Lambda, ECS, ECR, Elasticache, API Gateway etc)
Scripting languages - Python, bash, groovy
Experience in building CI/CD pipelines with Jenkins and Github Actions
Solid understanding of networking concepts
Experience with Infrastructure as Code tools such as Cloudformation and Terraform
Configuration management using Puppet or Ansible
Experience with Monitoring tools such as Datadog, Kibana
Experience with Package managers, Verdaccio, ECR, Github Packages
Experience with Container Image registries ECR
