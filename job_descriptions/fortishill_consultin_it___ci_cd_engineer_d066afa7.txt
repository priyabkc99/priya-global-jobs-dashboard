Our client is supporting a large-scale regulated technology programme in Hong Kong and is looking for an experienced CI/CD Engineer to build, enhance, and maintain enterprise CI/CD pipelines within a private on-premises cloud environment. This role is suitable for a hands-on engineer with strong experience in software deployment automation, container platform integration, and secure release processes for enterprise applications.




Key Responsibilities

CI/CD Framework Development

Design, implement, and maintain CI/CD pipelines using tools such as Bitbucket, Jenkins, or similar platforms.
Support deployment pipelines for web applications, Android applications, and iOS applications.
Integrate CI/CD pipelines with application platforms such as Red Hat OpenShift and database environments such as Oracle DB.
Ensure effective version control, automated testing, and controlled software delivery processes.

Application Deployment & Operations

Manage the software deployment lifecycle for both custom-built applications and commercial off-the-shelf solutions.
Deploy, configure, and support applications across platforms such as Nginx, MuleSoft API Gateway, Red Hat Directory Server, Red Hat Single Sign-On (RHSSO), Solace, and OpenShift / Kubernetes.
Support environment setup, release activities, and deployment coordination across application, testing, and operations teams.

Private Cloud & Infrastructure Tool Integration

Support integration with private cloud infrastructure and platform tooling.
Work with infrastructure tools and platforms including MuleSoft, CyberArk, HashiCorp, and EFK Logging.
Use Red Hat OpenShift and Kubernetes to support containerised application deployment and operations.

Security & Compliance in DevOps

Embed security controls throughout the CI/CD and deployment lifecycle.
Integrate security and credential management tools such as CyberArk, HashiCorp Vault, and Splunk to protect sensitive credentials and operational data.
Support secure deployment practices in a regulated enterprise environment.

Monitoring, Troubleshooting & Continuous Improvement

Monitor CI/CD pipeline performance and deployment outcomes to identify bottlenecks, failures, and improvement opportunities.
Troubleshoot issues during build, testing, deployment, and post-deployment phases.
Improve deployment stability, release efficiency, and automation maturity across delivery teams.

Cross-team Collaboration

Work closely with application teams, testing teams, platform teams, and deployment teams to support smooth delivery.
Provide guidance on version control, environment setup, deployment readiness, and operational handover.




Requirements

Bachelor’s degree in Computer Science, Information Technology, or a related discipline.
Minimum 3 years’ experience in DevOps, CI/CD, platform engineering, or related technical roles.
At least 2 years’ hands-on experience establishing and managing CI/CD frameworks in an enterprise environment.
Proven experience deploying applications in cloud or private cloud environments.
Strong hands-on experience with:
Bitbucket for version control
Jenkins or similar CI/CD tools
SonarQube for source code analysis
Red Hat OpenShift / Kubernetes
Oracle Database application deployment environments
Familiarity with infrastructure and middleware platforms such as Nginx, MuleSoft, Solace, Red Hat Directory Server, and RHSSO.
Strong troubleshooting and problem-solving skills.
Good communication skills, with the ability to work with both technical and non-technical stakeholders.
