Natalie Akermann

Azure DevOps Engineer




Location: Johannesburg
Experience: 8+ years
Workplace Type: in office 5 days a week




About the opportunity

Are you an experienced Azure DevOps Engineer who enjoys building reliable cloud platforms, automating delivery, and helping teams ship software faster and more securely? This is an opportunity to play a key role in designing, implementing, and managing scalable Microsoft Azure environments, CI/CD pipelines, infrastructure automation, and DevSecOps practices for enterprise-grade solutions.

You’ll work closely with development, testing, security, and operations teams to improve deployment quality, strengthen cloud resilience, and support modern engineering practices across the software delivery lifecycle.




What you’ll be doing

Design, build, and maintain secure, scalable Azure cloud infrastructure and DevOps solutions.
Develop, optimise, and manage CI/CD pipelines using Azure DevOps, GitHub Actions, or similar tools.
Automate infrastructure provisioning using Terraform, ARM Templates, or Bicep.
Implement and manage containerised workloads using Docker and Kubernetes, including Azure Kubernetes Service.
Monitor application and infrastructure performance using Azure Monitor, Log Analytics, and Application Insights.
Embed DevSecOps controls, security best practices, and vulnerability management into delivery processes.
Collaborate with cross-functional teams to streamline releases and improve engineering efficiency.
Manage Git-based source control, branching strategies, and release management processes.
Troubleshoot deployment, performance, infrastructure, and platform issues.
Support high availability, scalability, and disaster recovery across Azure environments.




What we’re looking for

You’ll bring strong hands-on experience in Microsoft Azure, automation, CI/CD, and modern DevOps practices. You should be comfortable working in complex environments where reliability, security, collaboration, and continuous improvement matter.




Required experience

8+ years’ relevant experience, with strong exposure to Azure DevOps engineering or cloud platform engineering.
Strong experience with Microsoft Azure cloud services, including networking, security, identity, monitoring, and resilience.
Hands-on experience building and maintaining CI/CD pipelines using Azure DevOps, GitHub Actions, or similar tooling.
Practical experience with Infrastructure as Code using Terraform, ARM Templates, or Bicep.
Experience with Docker, Kubernetes, and Azure Kubernetes Service.
Strong scripting capability using PowerShell, Bash, or Python.
Experience with Git-based source control and release management practices.
Understanding of Agile, DevOps, and Site Reliability Engineering practices.




Preferred qualifications and experience

Microsoft Azure certifications such as Azure Administrator Associate, Azure DevOps Engineer Expert, or Azure Solutions Architect Expert.
Experience in banking, financial services, or another regulated environment.
Exposure to multi-cloud environments such as AWS or Google Cloud Platform.
