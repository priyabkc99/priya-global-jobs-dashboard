Job Description



We are seeking an ambitious, hands-on DevOps Engineer (Google / GCP) to join our cloud platform team. In this role, you will be instrumental in modernizing, automating, and maintaining highly available Google Cloud environments and hybrid continuous delivery pipelines.



A primary focus for this position will be configuring, deploying, and integrating GitLab across both GCP and on-premises environments—ensuring seamless, secure code delivery and orchestration across hybrid infrastructure. Sitting at the intersection of development and operations, you will empower software squads to ship code faster, safer, and more reliably.



What You’ll Be Doing



Hybrid GitLab Integration: Configure, administer, and integrate GitLab across GCP and on-premises environments, creating seamless CI/CD pipelines, runner groups, and automated deployment patterns across hybrid infrastructure.



GCP Infrastructure Automation: Design, build, and maintain scalable cloud infrastructure using Terraform and Google Cloud native tools.



Pipeline Engineering: Build, optimize, and manage robust continuous integration and deployment pipelines for microservices, legacy systems, and cloud workloads.



Container Orchestration: Manage and fine-tune Google Kubernetes Engine (GKE) clusters, helm charts, and container registries to ensure reliable execution of workloads.



Observability & Reliability: Implement comprehensive monitoring, logging, and alerting systems using Google Cloud Operations (Stackdriver), Prometheus, Grafana, or Datadog to maintain peak platform reliability.



DevSecOps Integration: Embed automated security scanning, policy enforcement (IAM, Organization Policies), and vulnerability management directly into GitLab CI/CD pipelines.



Operational Excellence & Mentorship: Troubleshoot complex build and platform issues, participate in incident management, and share DevOps best practices across engineering squads.





Qualifications



Core Requirements:



GitLab & Hybrid Experience: Proven experience configuring, managing, and integrating GitLab (SaaS or Self-Managed) across hybrid environments (GCP and on-premises infrastructure).



GCP Expertise: Strong hands-on experience engineering and administering core Google Cloud Platform services (GKE, VPCs, IAM, Cloud Run, Cloud Functions, Pub/Sub, Cloud Storage).



Infrastructure as Code (IaC): Deep proficiency with Terraform for provisioned and version-controlled GCP and hybrid infrastructure.



Containers & Orchestration: Proven track record working with Docker and Kubernetes (specifically GKE).



Scripting & Automation: High proficiency in scripting languages such as Bash, Python, or Go.



Hybrid Networking & Security: Solid understanding of hybrid cloud networking (hybrid connectivity, VPNs, subnets, firewalls, load balancers, Cloud DNS) and IAM security fundamentals.



Highly Regarded:



Official certifications: GitLab Certified Associate/Professional or Google Cloud Certifications (Professional Cloud DevOps Engineer / Professional Cloud Architect).



Experience with GitOps methodologies (e.g., ArgoCD, Flux) and Helm.



Familiarity with service mesh architectures (Istio / Anthos Service Mesh).
