Job Description

Configuration and Delivery Manager would be responsible for configuration control, release coordination, deployment governance, and delivery readiness across current and upcoming WSP Digital Products. The role would ensure that product configuration, environment readiness, version control, release packages, deployment approvals, and production releases are managed through controlled, traceable, auditable, and repeatable processes across development, test, staging, and production environments.

Responsibilities

Configuration Management

Define and maintain configuration management standards across applications, environments, release packages, and deployment artefacts.

Maintain traceability for product versions, configuration items, environment variables, dependencies, release baselines, and deployment records.

Coordinate configuration changes across application, integration, data, infrastructure, and environment layers.

Ensure configuration decisions are documented, controlled, and auditable.

Release & Deployment Management

Plan, coordinate, schedule, and govern product releases across current and upcoming digital products.

Maintain release calendars, deployment schedules, release notes, release scope, deployment checklist, and rollback plans.

Coordinate release readiness reviews, QA sign-offs, DevOps readiness, CAB inputs, and production deployment approvals.

Track release risks, deployment issues, defects, rollback outcomes, and post-release validation status.

Environment & Delivery Readiness

Coordinate environment readiness across Dev, QA, UAT, staging, production, and support environments.

Ensure environment consistency, access readiness, dependency readiness, and deployment sequencing before release execution.

Support environment refresh, configuration updates, smoke-test coordination, and deployment troubleshooting.

Work with DevOps and engineering teams to improve repeatability and reliability of deployment practices.

Compliance, Metrics & Continuous Improvement

Maintain release evidence, approval records, deployment logs, release decisions, and audit-ready documentation.

Track release metrics including deployment frequency, failed deployments, rollback frequency, defect leakage, and release predictability.

Identify recurring release and configuration issues and drive preventive improvements with engineering, QA, DevOps, and support teams.

Contribute to release SOPs, configuration playbooks, governance checklists, and operational documentation.

Required Technical Skills

Configuration Management | Advanced — software baselines, version control, configuration item traceability, environment configuration, and audit records

Release Management | Advanced — release planning, deployment coordination, CAB inputs, release readiness, rollback planning, and sign-offs

DevOps / CI-CD Awareness | Proficient — Azure DevOps, GitHub, branching, tagging, pipelines, deployment controls, and release artefacts

Environment Governance | Proficient — Dev, QA, UAT, staging, production readiness, environment refresh, and deployment sequencing

ITIL / Change Governance | Proficient — change, release, configuration, risk-based approvals, governance documentation, and auditability

Stakeholder Coordination | Advanced — coordination across engineering, QA, DevOps, business, support, and leadership teams

Required Experience

Minimum 8 years of professional experience in configuration management, release management, DevOps coordination, IT operations, or software delivery governance.

Experience managing enterprise release cycles across multiple environments and product teams.

Experience with configuration baselines, release packages, deployment records, change controls, and audit-ready documentation.

Working knowledge of Azure DevOps, Git, branching strategies, build/release pipelines, and deployment governance.

Experience coordinating CAB approvals, release readiness, rollback planning, deployment validation, and post-release verification.

Preferred (Not Required)

Experience supporting SaaS, cloud-hosted, or integration-heavy enterprise digital products.

Exposure to ITIL Change, Release, and Configuration Management practices.

Experience with Azure DevOps, GitHub, Jira, ServiceNow, SharePoint, Confluence, or similar tools.

Exposure to product transition, MVP stabilization, or multi-vendor delivery models.

Qualifications


Bachelor’s degree in Computer Science, Information Technology, Engineering, or related field.
ITIL Foundation, DevOps, Agile, or Release Management certification is preferred but not mandatory.
