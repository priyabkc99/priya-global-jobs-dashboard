The Role

We are seeking a Senior GCP DevOps Engineer to lead the design, implementation, automation, and operational excellence of cloud-native platforms on Google Cloud Platform (GCP). This role requires an experienced professional capable of driving cloud transformation initiatives, establishing DevSecOps standards, and enabling secure, resilient, highly available enterprise platforms across regulated environments.

The ideal candidate will possess deep expertise in GCP, Kubernetes, Infrastructure as Code, CI/CD automation, observability, Site Reliability Engineering (SRE), and cloud security, while partnering with architecture, engineering, risk, and operations teams.




Your responsibilities:




Cloud Platform Engineering

Design and implement secure, scalable, and highly available cloud platforms on GCP.
Lead enterprise cloud migration and modernization initiatives.
Define platform standards, reusable cloud patterns, and infrastructure blueprints.
Architect multi-region disaster recovery and high-availability solutions.

DevOps and Automation

Establish and govern enterprise CI/CD frameworks.
Automate infrastructure provisioning using Terraform and Infrastructure as Code principles.
Drive environment automation, release automation, and deployment strategies.
Implement GitOps and platform engineering best practices.

Kubernetes and Container Platforms

Design and manage large-scale GKE environments.
Standardize container deployment frameworks and operational processes.
Optimize cluster security, scalability, networking, and performance.
Define container governance and platform best practices.

Reliability Engineering

Implement SRE practices, including SLIs, SLOs, and error budgets.
Build enterprise monitoring, observability, logging, and alerting frameworks.
Lead incident management, problem management, and root cause analysis.
Improve system reliability and operational efficiency through automation.

Security and Compliance

Implement DevSecOps controls across the software development lifecycle.
Design IAM strategies and privileged access controls.
Ensure alignment with banking, GDPR, and enterprise security requirements.
Drive vulnerability management, secrets management, and policy-as-code implementations.

Leadership and Stakeholder Management

Mentor engineers and DevOps teams.
Collaborate with enterprise architects, security teams, and senior stakeholders.
Provide technical governance for cloud adoption initiatives.
Review designs, conduct architecture assessments, and recommend improvements.







Your Profile:




Essential skills/knowledge/experience:




Google Cloud Platform

Google Kubernetes Engine (GKE) • Cloud Build and Cloud Run • Cloud Storage • VPC and network architecture • IAM and security controls • Secret Manager • Cloud Operations Suite, including Monitoring and Logging • Load Balancing • Pub/Sub • BigQuery • Cloud SQL




Infrastructure as Code

Terraform at expert level • Reusable Terraform modules • Remote state management and governance • Policy as Code




Containerization and Orchestration

Kubernetes • Docker • Helm • Service mesh, preferably Istio




CI/CD and Automation

Cloud Build • Jenkins • GitHub Actions • GitLab CI/CD • Argo CD • GitOps frameworks




Scripting and Development

Python • Shell scripting • YAML • REST APIs




Monitoring and Observability

Cloud Monitoring • Cloud Logging • Prometheus • Grafana • OpenTelemetry




Banking and Financial Services Experience

Financial services

Regulatory reporting
Compliance and risk platforms

Experience supporting regulated environments and enterprise security standards is highly desirable.
