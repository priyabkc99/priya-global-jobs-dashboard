Project Description:

We are seeking a highly skilled Senior DevOps Developer to drive CI/CD, automation, and platform engineering initiatives across the Investment Banking & Markets (IB&M) domain in a large enterprise services environment. The role focuses on building and operating robust CI/CD pipelines, infrastructure and application automation with cloud services, standardized release and deployment frameworks for multiple critical applications and exploring AI-assisted automation for operational intelligence. You need to have strong experience working across a complex application landscape, with a primary focus on Infrastructure as Code (IaC), release engineering, deployment automation, and operational utilities, while collaborating closely with Release Teams, Application Teams, and Service Teams.




Responsibilities:

Design, build, and maintain enterprise-grade CI/CD pipelines using GitLab Enterprise
Lead automation initiatives across the IB&M domain to reduce manual effort and improve reliability
Develop and manage Infrastructure as Code (IaC) for application and platform deployments
Standardize and execute release and deployment processes across multiple applications
Provision and manage AWS and Azure infrastructure, including Kubernetes platforms (EKS/AKS)
Build and maintain containerized delivery pipelines using Docker, Podman, and Helm charts
Automate configuration management and operational tasks using Ansible and Python
Collaborate closely with Release, Application, Cloud, Security, Database, and Platform teams
Integrate database automation for Oracle and PostgreSQL
Integrate security and compliance scans (Checkmarx, secret scans, vulnerability checks, and internal tools)
Create and maintain detailed documentation, including CI/CD pipelines, IaC modules, deployment runbooks, and SOPs
Integrate logging, monitoring, and observability using cloud-native tools and Splunk
Perform ad-hoc operational, automation, and tooling tasks as required in an enterprise setup
Explore AI-driven pipeline optimizations, automated validation, and predictive remediation




Mandatory Skills Description:

7+ years of relevant experience in DevOps, CI/CD, or Platform Engineering within enterprise environments (IB&M / financial services)
Strong hands-on experience with GitLab Enterprise, including pipelines, runners, and repository management
Deep expertise in CI/CD design, release engineering, and deployment automation
Strong hands-on experience with AWS/Azure services.
Strong experience with containerization technologies: Docker and Podman
Hands-on experience with Kubernetes and Helm for application deployments
Proven experience implementing Infrastructure as Code (IaC) and automation frameworks
Strong automation and scripting skills using Python and configuration management with tools such as Ansible
Solid understanding of Databases Oracle & Postgres and Operating systems Linux/Unix
Experience working with logging and observability tools with cloud native & tools like Splunk
Proven experience integrating security and compliance scans into CI/CD pipelines
Strong documentation skills using Confluence and experience working with Jira
Strong understanding of ITIL processes
Excellent verbal and written communication skills.




Nice-to-Have Skills Description:

Understanding of ITIL processes is a plus
