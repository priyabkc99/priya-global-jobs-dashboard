Job Description

Transient.ai – a fintech AI company providing real-time intelligence and automated workflows for institutional finance. We empower asset managers, traders, and banks to make faster, data-driven decisions.

"We are looking for a skilled DevOps Engineer with strong Microsoft Azure experience to support and scale our cloud infrastructure. You will work remotely from India and collaborate closely with our New York–based engineering, product, and operations teams. In this role, you will own cloud infrastructure, CI/CD pipelines, deployment automation, monitoring, and system reliability. Experience with other cloud platforms such as AWS or GCP is a plus, as we value engineers with a broad cloud perspective and the ability to work in multi-cloud or evolving environments".

What You'll Do


Design, build, and maintain cloud infrastructure primarily on Microsoft Azure
Automate provisioning & deployments using Infrastructure as Code (Terraform, ARM, Bicep)
Develop and manage CI/CD pipelines for continuous integration and delivery
Manage containerized workloads using Docker and Kubernetes (AKS)
Implement monitoring, logging, and alerting using Azure Monitor, Application Insights, or similar tools
Ensure system scalability, high availability, and disaster recovery
Collaborate with development teams to improve deployment frequency and system reliability
Implement and maintain cloud security best practices (IAM, secrets management, network security)
Troubleshoot infrastructure and application issues across environments
Participate in on-call rotations and incident management
Support cloud cost optimization and performance tuning initiatives


Required Skills & Qualifications


4–5 years in DevOps / Cloud Engineering roles
Strong hands-on experience with Microsoft Azure
Experience with CI/CD tools (Azure DevOps, GitHub Actions, GitLab CI, Jenkins, etc.)
Proficiency in Infrastructure as Code (Terraform preferred)
Hands-on experience with Docker and Kubernetes (AKS)
Strong understanding of Linux systems, networking, and cloud security
Scripting experience in Bash, PowerShell, or Python
Experience supporting production-grade, high-availability systems


Nice To Have (Additional Cloud & Tools Experience)


Experience with AWS (EC2, EKS, S3, RDS, IAM, CloudWatch)
Experience with Google Cloud Platform (GCP) (GKE, Compute Engine, Cloud Storage)
Exposure to multi-cloud or hybrid cloud architectures
Familiarity with cloud-agnostic tooling and patterns
Knowledge of serverless platforms (Azure Functions, AWS Lambda, GCP Cloud Functions)
Experience with service meshes, API gateways, or ingress controllers
Knowledge of SRE practices and reliability engineering
Cloud certifications (Azure, AWS, or GCP)


Working Hours & Collaboration


Ability to work 4–5 hours overlap with US Eastern Time (EST)
Experience working with distributed, global teams
Strong communication skills in English for effective collaboration.
