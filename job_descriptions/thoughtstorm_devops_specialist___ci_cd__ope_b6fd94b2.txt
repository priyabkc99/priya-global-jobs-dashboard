DevOps Specialist – CI/CD, OpenShift & Cloud Automation

We are seeking an experienced DevOps Specialist to support digital transformation and modern application delivery initiatives for the Government of Alberta, working within cross-functional product and delivery teams.
Design, build and maintain CI/CD pipelines, deployment templates and automation frameworks to enable reliable, frequent and low-downtime application releases in large-scale enterprise environments.
Bring hands-on expertise with GitHub Actions, Infrastructure as Code (IaC), Terraform, Red Hat OpenShift and Hybrid Cloud application deployment.
Develop PowerShell/scripts, tools and automated processes for environment provisioning, application deployment, maintenance and reduction of manual operational activities.
Support production operations, including configuration and credential management, maintenance, database upgrades/migrations, backups and recovery, while applying security best practices such as secrets management and least privilege.
Implement monitoring, telemetry and observability solutions and support integration, security, system, performance and load testing throughout the delivery lifecycle.
Experience with AWS, Azure or GCP, enterprise DevOps practices, command-line tools and emerging Generative AI/agentic automation is highly valuable. This is a primarily remote role, with occasional work sessions in Edmonton, Alberta, and work must be performed within Canada.
