ABOUT THE POSITION

A leading enterprise within the financial services sector is seeking an experienced DevOps Engineer to support and optimise modern cloud and hybrid infrastructure environments.

This role requires a highly independent, delivery-focused professional with deep expertise in DevOps principles, CI/CD automation, and multi-environment deployments across cloud and on-premise platforms. The successful candidate will work within a fast-paced, compliance-driven environment where reliability, scalability, and security are critical.

Key Responsibilities

Design, implement and optimise CI/CD pipelines
Automate infrastructure provisioning and deployment processes
Deploy and manage workloads across AWS, Kubernetes, and on-premise environments
Implement DevOps best practices, patterns, and governance standards
Collaborate with development, QA, security, and infrastructure teams
Improve release cycles, build reliability, and deployment automation
Monitor, troubleshoot, and optimise system performance and availability
Ensure secure DevOps practices within a regulated enterprise environment

Minimum Requirements
Experience

Proven experience as a DevOps Engineer within enterprise environments
Strong hands-on experience with Azure DevOps
Experience with GitHub Actions (advantageous)
Experience deploying solutions to:
AWS
Kubernetes (K8s)
On-premise server environments
Solid understanding of CI/CD pipeline design and automation
Experience working in regulated or financial services environments (advantageous)

Technical Skills

DevOps principles and patterns
CI/CD pipeline implementation
Infrastructure as Code (Terraform/ARM/Bicep advantageous)
Containerisation and orchestration (Docker, Kubernetes)
Cloud deployments (AWS; Azure exposure advantageous)
Source control and branching strategies
Release management and deployment governance
Scripting (PowerShell, Bash, or Python advantageous)
Monitoring and logging tools

Behavioural Competencies

Highly independent and self-driven
Strong delivery and deadline focus
Analytical problem-solving ability
Excellent stakeholder communication skills
Ability to operate within structured governance environments
