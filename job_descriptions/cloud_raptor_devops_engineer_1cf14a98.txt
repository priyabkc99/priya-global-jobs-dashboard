Cloud Raptor – Senior DevOp Engineer

Capital Markets, Post Trade & Payments

Location: Sydney

Client: Enterprise Financial Services Organisation

Role Type: Senior DevOps Engineer

Overview

The client is seeking an experienced Senior DevOps & Platform Engineer to support the delivery, automation, security, and operational excellence of critical post-trade and payments platforms.

Working across cloud, infrastructure, application, and engineering teams, you will help build and operate secure, highly available, cloud-native platforms that support trading operations, settlements, payments processing, and enterprise technology services.

This role is ideally suited to a DevOps or Platform Engineer with strong Kubernetes expertise, cloud engineering capability, Infrastructure-as-Code experience, and a passion for automation, platform reliability, and developer enablement.




Key Responsibilities

**Terraform Experience

**EKS SME

•Design, build and maintain enterprise CI/CD pipelines and deployment automation frameworks.

•Develop and operate Kubernetes-based platforms supporting multiple engineering teams.

•Implement GitOps deployment practices using tools such as ArgoCD, FluxCD, Helm and Terraform.

•Automate infrastructure provisioning and platform lifecycle management through Infrastructure-as-Code.

•Support cloud-native application delivery across AWS, Azure, and hybrid environments.

•Build and maintain observability solutions including monitoring, logging, alerting and operational dashboards.

•Improve platform reliability, scalability, security and operational resilience.

•Implement secrets management and secure platform controls across multiple environments.

•Support release management, production deployments and service reliability initiatives.

•Collaborate with development teams to improve developer experience and delivery velocity.

•Assist with incident management, root cause analysis and continuous improvement activities.

•Contribute to platform governance, security standards and operational best practices.

Essential Experience

Terraform

•Solid understanding of core Terraform concepts, including resources, modules, data sources, locals, variables, providers, and outputs.

•Experience with different Terraform code execution whether running locally or through CI/CD pipelines, and the ability to troubleshoot pipeline-related issues.

•Awareness of Terraform security best practices, including state file protection, policy enforcement (OPA/Sentinel), and code scanning/security validation.

EKS/Kubernetes

•Good understanding of Kubernetes architecture, including the control plane, worker nodes, scheduler, and other core components.

•Experience with workload types such as Deployments, Stateful Sets, Replica Sets, Jobs etc.

•Knowledge of EKS security concepts, including IAM integration, RBAC, network access controls/endpoints, and policy enforcement tools such as Kyverno or Gatekeeper.

CI/CD

•Experience designing and implementing CI/CD pipelines with appropriate validation, error handling, and logging.

•Understanding of Docker builds, container images, image scanning, and container registries.

•Experience with reusable pipeline components/shared libraries and secure secrets management practices.

•Strong DevOps, Platform Engineering or Site Reliability Engineering experience.

•Strong AWS experience with exposure to Azure and/or GCP highly regarded.

•Experience implementing GitOps operating models.

•Expertise with:

o Kubernetes o Helm o Docker o Terraform o GitHub Actions o Jenkins o ArgoCD o FluxCD

•Strong automation and scripting capability using Python, Bash or similar languages.

•Experience implementing Infrastructure-as-Code solutions.

•Experience with secure platform engineering and secrets management solutions.

•Strong understanding of Linux systems and cloud-native architectures.

•Experience supporting business-critical enterprise platforms in regulated environments.
