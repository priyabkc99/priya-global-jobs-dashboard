Our client, an established industrial software company working with manufacturing and industrial automation, are looking for a Software QA Engineer with a strong focus on release management and production deployment. You will own the path from “development is complete” to “the software is running correctly at the customer plant.” This includes testing release candidates, preparing and versioning releases, installing updates remotely, verifying production systems and improving the process through automation.




This is not a standard manual web-testing position. You will work directly with Windows Server, SQL Server, .NET applications, PowerShell, logs, VPN connections and live customer environments.




What you will do

Test new features, release candidates and bug fixes
Run system-level regression tests using our automated extrusion press simulator
Prepare, package and version software releases
Maintain release branches, tags and deployment records in Git
Connect to customer servers remotely through VPN and RDP
Deploy .NET Windows services and IIS web applications
Apply and verify SQL Server schema and data updates
Take database backups and prepare rollback plans before making changes
Verify services, logs, database writes, operator screens and PLC communication after deployment
Maintain records of the software versions and configurations installed at each customer site
Investigate whether production issues are related to software, configuration, databases or connected equipment
Automate repeatable testing and deployment tasks using PowerShell
Help develop our automated build, test and release pipeline




What we are looking for

Practical Windows Server administration experience
Experience with Windows services, IIS, Event Viewer, permissions and RDP
Working SQL Server and T-SQL knowledge
Experience running database scripts and taking or restoring backups
PowerShell or equivalent scripting experience
Working knowledge of Git branches, tags and release workflows
Familiarity with building, testing or publishing .NET applications
Experience deploying or supporting software in a production environment
A careful and structured approach to testing, documentation, backups and rollback planning
Strong troubleshooting skills
Good written and spoken English
Availability for occasional installations during customer maintenance windows outside normal office hours
Currently living in Malta and legally permitted to work in Malta




Useful additional experience

Supporting on-premises software installed at customer sites
CI/CD systems such as Azure DevOps, GitHub Actions or Jenkins
Reading and troubleshooting C# code
Automated testing frameworks such as xUnit
Industrial automation, MES or SCADA systems
Siemens or Allen-Bradley PLCs
OPC UA, OPC DA or Modbus
Software installer or packaging tools




What makes the role interesting

Take ownership of the complete testing and release process
Work directly with the lead developer and a small technical team
Improve and automate how software is tested and delivered
Work on software connected to real industrial production machinery
Gain experience with customer plants and extrusion systems around the world
Build on an existing automated test suite and press simulator
