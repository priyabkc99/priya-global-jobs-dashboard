Job Description

Seeking a hands-on DevOps Engineer to build, operate, and scale cloud-native infrastructure and CI/CD pipelines. The ideal candidate has strong AWS experience, containerization skills, solid database knowledge (PostgreSQL, MongoDB, Redis), and deep familiarity with Git workflows and collaboration.

Role and Responsibilities


Design, implement, and maintain AWS infrastructure (EC2, ECS/EKS, Lambda, VPC, IAM, S3, RDS, CloudFormation/Terraform, CloudWatch).
Build and operate CI/CD pipelines using tools like GitHub Actions, GitLab CI, or Jenkins; enforce reliable, repeatable deployments.
Containerize applications and manage container platforms using Docker and orchestration (ECS/EKS/Kubernetes).
Administer and optimize databases: PostgreSQL (schema design, backups, replication, performance tuning), MongoDB (sharding, indexing, replica sets), and Redis (caching, data structures, persistence).
Implement infrastructure as code (Terraform/CloudFormation) and configuration management (Ansible/Chef/Puppet).
Implement monitoring, logging, alerting, and incident response practices (Prometheus/Grafana, ELK/EFK).
Collaborate with developers on Git workflows: branching strategies, rebasing, merging, resolving conflicts, PR reviews, and release management.
Automate security, secrets management, and compliance checks (AWS IAM best practices, Vault/Secrets Manager).
Troubleshoot production issues, conduct postmortems, and drive reliability improvements.


Person Specification (Skills; knowledge; experience; attitude)


3+ years professional DevOps/SRE experience.
Strong AWS experience with core services listed above.
Proficient with Docker and container lifecycle (image creation, registries, runtime).
Practical experience with PostgreSQL and MongoDB administration and performance tuning.
Experience operating Redis for caching or ephemeral data.
Solid Git skills: branching strategies (Git Flow/Trunk-Based), rebasing, conflict resolution, code review practices.
Experience with CI/CD tooling and automation scripting (Bash, Python, or similar).
Experience with infrastructure-as-code (Terraform or CloudFormation).
Strong troubleshooting, communication, and collaboration skills.
